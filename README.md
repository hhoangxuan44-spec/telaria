# 泰拉瑞亚 · 昼夜生态

一个纯前端（无依赖）的泰拉瑞亚风格动态场景，直接打开 `index.html` 或用 GitHub Pages 托管即可。

## 特性

- **真实时钟驱动的昼夜循环**：默认与本地时间同步（泰拉瑞亚规则：4:30 AM 日出，7:30 PM 入夜）。
- **真实月相**：同步模式下按天文算法计算当天月相，并使用 `Category_Moon_phase_images` 的 8 张月相图；加速模式下每天推进一个月相，和游戏里一样。
- **金表时钟**：左上角像素金表 + 数字时间、天数与时段。
- **动态光照**：按格子传播的泰拉瑞亚式光照，夜晚变暗，火把、篝火、岩浆、血腥之心宠物、法球、坠落之星都会发光；地下洞穴只有光源附近可见。
- **血月**：每晚约 1/9 概率自然出现（新月除外），也可用物品栏 7 召唤或驱散。
- **生态**：7 个玩家动作、18 只宠物（跟随主人）、全部坐骑（走 / 停 / 飞 / 游泳等状态切换），池塘里有海龟和猪鲨，地下岩浆池里有岩浆鲨，白天蝴蝶、夜晚萤火虫。
- **天空**：全部云朵素材随风飘动，偶尔出现彩蛋云；夜空星星闪烁、流星划过；坠落之星会落地，可点击收集。
- **音乐**：白天正常播放，夜晚自动加低通滤波并降低音量，还有程序生成的蟋蟀声。
- **界面**：泰拉瑞亚风格物品栏、生命值、小地图（点击可跳转）、信息附件（月相 / 时间模式 / 风速）、聊天提示。

## 操作

| 操作 | 作用 |
| --- | --- |
| 拖动 / 滑动 / 滚轮 / ← → / A D | 浏览世界 |
| 点击生物 | 互动（跳一下、冒爱心） |
| 点击坠落之星 | 收集 |
| `1` `2` `3` `4` | 跳到黎明 / 正午 / 黄昏 / 午夜 |
| `5` | 切换时间流速：1× → 60×（泰拉瑞亚原速）→ 600× → 暂停 |
| `6` | 重新与现实时间同步 |
| `7` | 召唤 / 驱散血月 |
| `8` | 音乐开关 |
| `9` | 闲置时镜头自动巡游 |
| `0` | 查看收集到的坠落之星 |

## 调试参数

`index.html?time=21.5&speed=60&phase=0&blood=1&overlay=0&tour=0&seed=123`

- `time`：起始小时（0–24），会切换到泰拉时间模式
- `speed`：0 / 1 / 60 / 600
- `phase`：月相 0–7（0 满月，4 新月）
- `blood=1`：当晚强制血月
- `overlay=0`：跳过启动界面
- `tour=0`：关闭镜头巡游
- `seed`：世界生成种子

## 文件结构

- `index.html`：页面结构
- `css/style.css`：界面样式
- `js/main.js`：世界生成、光照、时间系统、生物 AI、渲染
